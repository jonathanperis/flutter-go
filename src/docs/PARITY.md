# API parity with Flutter

Generated by `go run ./src/cmd/apiparity`; do not edit by hand.

The Dart side is the Dart analyzer's view of each library (`src/cmd/apiparity/dart`):
its public top-level declarations (classes, mixins, enums, typedefs, functions,
variables), each class's, mixin's and enum's declared public members
(constructors, fields, getters, setters, methods, operators, enum values; members
only inherited from a superclass or mixin count where they are declared, implicit
default constructors and enums' `values` don't count) and the parameters of every
constructor, method and function. A name counts for the library whose `src/<lib>/`
declares it; names a library re-exports from a third-party package (foundation's
package:listen) count for that library.

**Exposed** means the Go package of the library declares it under the name
[API_MAPPING.md](API_MAPPING.md)'s rules give (constructors `NewX`/`NewXName`, getters
as methods or fields, setters `SetX`, statics `TypeMember` or a package struct
variable, operators `Add`/`Sub`/`Equal`..., named parameters as option fields), or
through an entry of [api_divergences.json](api_divergences.json): a documented rename
or Go impossibility, each citing its API_MAPPING section (**Divergent** counts them).
**Tested** means a `_test.go` file in the repository (difftests included) refers to
the Go declaration, resolved by go/types (a class also counts when its members do;
test packages that don't type-check count by the names they mention). Parameters
count as exposed when the Go function they map to takes them (by name, else in
order; named ones as option fields); the parameters of a missing member are missing.
